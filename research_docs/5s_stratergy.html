Core Analysis: How Long Should the Video Snippet Be?

Selecting the right snippet duration is critical. Too short, and the gesture lacks contextual pre-stroke and post-stroke movement. Too long, and the model struggles with background noise, idle frames, and excessive computational load. Select a sign type below to view the optimal temporal window.

1.5 to 3.0 Seconds

Optimal for Isolated Words

  • ✓ Pre-stroke (0.5s): Captures the hand moving into the starting position.
  • ✓ Nucleus (1.0 - 2.0s): The core movement of the Sinhala sign.
  • ✓ Post-stroke (0.5s): Hand returning to a resting state.

Key Environment Variables

☀ Lighting Angles

Ensure 30% of data includes challenging lighting (backlit, side-lit, low light) to improve real-world model robustness.

👕 Clothing Interference

Avoid exclusive use of tight-fitting, high-contrast clothing. Include loose sleeves and skin-matching tones.

□ Background Noise

Transition from plain white/green screens to dynamic backgrounds (rooms, outdoors) for 50% of the dataset.

Technical Specifications Matrix

Parameter Recommended Value Rationale for SSL
Frame Rate 30 FPS (Frames Per Second) 60 FPS is overkill and doubles dataset size. 30 FPS perfectly captures fast finger movements without blurring.
Resolution 1080p downscaled to 224x224 Record in 1080p for archival quality, but crop/downscale to 224x224 or 256x256 for standard CNN/RNN model input.
Repetitions 15-20 per sign, per person Captures intra-class variability. A user will never sign the same word exactly the same way twice.
Vocabulary Size Start: 50-100 Words For an initial prototype, focus on a high-frequency lexicon (Greetings, Family, Emergency) before scaling up.
