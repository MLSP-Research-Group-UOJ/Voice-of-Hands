LABEL MEANINGS:
===============

LEFT SIDE - Detailed Status:
  • Status: Shows WHY frame is idle/active
    - "ACTIVE SIGNING" (Green) = Active signing detected
    - "IDLE (Horizontal Hands)" (Orange) = Resting position  
    - "IDLE (Low Motion)" (Gray) = Below motion threshold
  
  • Motion: Current motion energy value
  • Threshold: Motion threshold setting
  • Hands: Whether hands are detected by MediaPipe

RIGHT SIDE - Quick Status (NEW!):
  • Resting: YES/NO
    - YES (Orange) = Forearms horizontal, hands in rest position
    - NO (Gray) = Not in rest position
  
  • Status: ACTIVE/IDLE
    - ACTIVE (Green) = Currently signing
    - IDLE (Gray) = Currently idle

COLOR CODING:
=============
🟢 Green    = Active/Detected
🟠 Orange   = Resting position
⚪ Gray     = Idle/Not detected  
🔵 Cyan     = Threshold reference
⚪ White    = Neutral info


USAGE:
======
python sign_activity_detector.py video.mp4 output/ --visualize --threshold 0.02

Watch the right side labels to quickly see:
  • "Resting: YES" → Hands in horizontal rest position
  • "Resting: NO" → Hands not in rest position
  • "Status: ACTIVE/IDLE" → Current activity state
